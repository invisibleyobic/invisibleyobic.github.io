новое, ждёт решения

Лендинг-меню (стекло, окна из карточек)

asherbakov.ru/ozotens-menu/

  • Переупаковка лендинга по рефам: тёмно-бирюзовое стекло, засечки с курсивом, фото товара в тумане (Higgsfield)
  • Первый экран: одно обещание и одна кнопка «Открыть меню», предупреждение о противопоказаниях
  • Меню из фото-карточек с фильтром (Метод / Набор / Безопасность), карточки перестраиваются плавно (GSAP Flip)
  • Тап по карточке - раздел раскрывается из неё на весь экран, закрывается обратно в карточку; на телефоне можно смахнуть вниз
  • «Где болит?»: выбор области, размер M / L / XL сбоку, количество и «В заказ» (как карточка бургера в рефе)
  • «Набор»: прибор + крем + выбранный электрод, сумма, «Всё в заказ». Корзина общая с магазином
  • Плавная прокрутка Lenis, на компьютере своя раскладка: сетка-мозаика и окна по центру
История правок
  • 12.10 - первая версия, GSAP и Lenis по слову владельца

«Выбери путь» v2 (ущелье, стекло, золото)

asherbakov.ru/vyberi-put-v2/

  • Те же три пути, оформление по рефам: туманное ущелье с золотым лучом, шалфей, стекло, засечки
  • Первый экран: окно в стиле командной строки, «Проснись, вайб-кодер!» печатается через перебор символов со сбоями (глич)
  • Уведомление как на часах: «Время размяться. Сидишь уже 2 ч 47 мин» - минуты растут, пока открыта страница, кнопка «Встаю»
  • Водопад течёт: вода и брызги рисуются в коде поверх картинки (видео из Higgsfield - когда вернётся лимит)
  • Отдельный экран «Тело всё помнит!»: блок замирает, буквы влетают крупно, вспышка и сбой
  • «Выбери свой путь:» - руки Нео в золотом свете с тремя капсулами, капсула открывает путь
  • Путь 1 «Помочь себе где угодно», путь 3 «Помог себе - помоги другим» (намёк на своё дело)
  • «специалистом» в финале - ссылка на клиники Медозонс. Прокрутка стала резче
  • GSAP + ScrollTrigger + ScrambleText + Lenis, свои копии; без них и при «уменьшить движение» всё видно сразу
История правок
  • 12.10 - первая версия
  • 13.10 - починено: при возврате наверх пропадала панель «Проснись, вайб-кодер»; на ПК панель ровно по центру
  • 14.10 - правки владельца: командная строка, глич, «Время размяться», «Тело всё помнит!», руки с капсулами, водопад, тексты путей, резче прокрутка, логотип-капсула вместо креста
